# Бот бронирования — кофейня «Манас»

Принимает заявки на бронь столика прямо в Telegram: имя → телефон → дата → время →
количество гостей → подтверждение. Также показывает меню по кнопке.

Что делает бот:
- /start — приветствие и две кнопки: «Забронировать столик» и «Меню»
- Бронь собирается пошагово, в конце — сводка клиенту
- Если задать ADMIN_CHAT_ID — все заявки дублируются тебе в личку

## Шаг 1. Получить токен бота

1. Открой Telegram, найди @BotFather
2. Отправь /newbot, придумай имя и юзернейм (должен заканчиваться на bot)
3. BotFather пришлёт токен — сохрани его

## Шаг 2. Узнать свой chat_id (не обязательно)

Напиши боту @userinfobot — он пришлёт твой числовой ID (это ADMIN_CHAT_ID).

## Шаг 3. Деплой на Railway

1. Зайди на railway.app, зарегистрируйся через GitHub
2. New Project → Deploy from GitHub repo → выбери этот репозиторий
3. В Variables добавь BOT_TOKEN и, если нужно, ADMIN_CHAT_ID
4. Railway сам поставит зависимости и запустит python bot.py

## Шаг 4. Проверка

Найди бота в Telegram по юзернейму, нажми /start, пройди сценарий брони.
